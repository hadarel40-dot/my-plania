# AI Video Editor (MVP)

עורך וידאו בדפדפן עם וריאציות AI. העורך לא משנה קבצי וידאו. הוא עורך "מתכון" (JSON של קליפים,
חיתוכים, כתוביות ו-looks), והתצוגה מורכבת בזמן אמת עם Remotion.

## הרצה

```bash
cd video-editor
npm install
npm run dev        # http://localhost:3000
```

בלי מפתחות API הכול רץ במצב דמו מקומי. להפעלת הענן, ראו "מצב ענן" למטה.

## מה עובד

| אזור | יכולות |
|------|--------|
| **ספריית מדיה** (ימין) | 3 קליפים לדוגמה, העלאת קבצים (כפתור או גרירה), לחיצה כפולה מוסיפה לציר הזמן |
| **נגן** (מרכז) | תצוגה חיה של כל הפרויקט, ניגון, צעד פריים, החלפת יחס 9:16 / 16:9 / 1:1 |
| **ציר זמן** (תחתית) | גרירה לסידור מחדש, trim בקצוות, פיצול (`S`), מחיקה (`Delete`), undo/redo (`Ctrl+Z` / `Ctrl+Shift+Z`), זום, גלילה בסרגל |
| **וריאציות AI** (שמאל) | prompt + סגנון + עוצמה + כמות, כרטיסים עם סטטוס והתקדמות, hover מנגן, לחיצה מציגה בנגן לפני החלה, ✓ מחיל, "שנה את זה", "עוד כמו זה", דירוג, מיון, חזרה למקור |
| **כתוביות** | תמלול אוטומטי (מדומה בדמו, Whisper בענן), עריכת טקסט, 3 סגנונות, הזזה על ציר הזמן |
| **שמירה** | שמירה אוטומטית בדפדפן (גם קבצים שהועלו), שחזור אחרי רענון, "פרויקט חדש" |
| **דמו / ענן** | מתג בסרגל העליון. הענן זמין רק כשמוגדר `FAL_KEY` בשרת |
| **ייצוא** | הורדת הפרויקט כ-JSON |

## מצב ענן (fal.ai)

1. מעתיקים `.env.example` ל-`.env.local` וממלאים `FAL_KEY` ו-`FAL_VIDEO_MODEL`.
2. מריצים `npm run dev`. העורך עובר אוטומטית למצב "ענן".

מה קורה מאחורי הקלעים:
- **וריאציות** (`lib/ai/fal-provider.ts`): קובץ המקור עולה פעם אחת ל-fal storage, נשלח לתור של המודל עם
  `video_url`, `prompt` (כולל רמז הסגנון), `strength` ו-`seed`, והסרטון שחוזר נכנס לספרייה ולכרטיס.
  כל מודל מצפה לשדות קצת אחרים: מה שחסר מוסיפים ב-`FAL_VIDEO_EXTRA_INPUT`, ואם שמות השדות שונים,
  משנים את ה-`input` בקובץ הזה.
- **תמלול** (`lib/ai/transcriber.ts`): Whisper על כל קובץ מקור, והמקטעים ממופים לציר הזמן לפי החיתוכים.
- **אבטחה** (`app/api/fal/proxy/route.ts`): המפתח נשאר בשרת. ה-proxy מתיר רק את המודלים שהוגדרו,
  ופתוח רק ב-`npm run dev` עד שיתווסף Auth.

שימו לב:
- המודל מקבל את כל קובץ המקור, לא רק את הקטע שנחתך. לקבצים ארוכים כדאי לחתוך לפני ההעלאה.
- הסכום שמוצג על הכפתור הוא הערכה גסה בלבד. המחיר האמיתי נקבע לפי המודל בעמוד שלו ב-fal.
- מצב הענן נבדק רק עד שלב היציאה ל-fal: ההגבלות של ה-proxy, הפעלת המצב וטיפול בשגיאות.
  קריאה אמיתית למודל עדיין לא נבדקה עם מפתח אמיתי.

## מה מדומה במצב דמו

- **וריאציות:** `lib/ai/provider.ts` (`mockProvider`) מדמה תור ועיבוד, ומחזיר "look" (פילטר צבע / זום / היפוך) על אותו קובץ במקום וידאו חדש.
- **העלאה:** `lib/media/local-upload.ts` שומר את הקובץ בדפדפן (IndexedDB), לא בענן.
- **תמלול:** `lib/ai/mock-transcribe.ts` מחזיר טקסט לדוגמה.

## מבנה

```
app/                     עמוד אחד, העורך נטען בצד הלקוח בלבד
components/editor/       editor · preview · timeline · variants-panel · media-bin · caption-inspector
remotion/                TimelineComposition: אותה קומפוזיציה לתצוגה ולרינדור הסופי
stores/editor-store.ts   מצב העורך (Zustand + Immer + zundo ל-undo)
stores/playback-store.ts מצב הניגון (מופרד כדי לא להיכנס להיסטוריה)
lib/ai/                  ממשק ספק, ספק דמו + ספק fal, סגנונות, תמלול (דמו / Whisper)
lib/persistence.ts       שמירה אוטומטית (localStorage + IndexedDB)
app/api/                 config (מה זמין בענן) · fal/proxy (המפתח נשאר בשרת)
lib/editor/              טיפוסים ופונקציות ציר זמן
supabase/migrations/     סכמה לשלב הענן
```

## השלבים הבאים

1. **Supabase:** Auth (וחסימת ה-proxy למשתמשים מחוברים בלבד), שמירת `edit_projects.timeline` בענן, טבלת `variants`.
2. **העלאה לענן:** Mux Direct Upload או S3 multipart במקום `importLocalFile`, ו-proxy 720p + thumbnails.
3. **Jobs בצד השרת:** העברת הקריאות ל-fal ל-Inngest + webhook, כך שוריאציה ממשיכה לרוץ גם אם סוגרים את הדף.
4. **רינדור:** Remotion Lambda על `TimelineComposition` עם קבצי המקור.
