# AI Video Editor (MVP)

עורך וידאו בדפדפן עם וריאציות AI. העורך לא משנה קבצי וידאו. הוא עורך "מתכון" (JSON של קליפים,
חיתוכים, כתוביות ו-looks), והתצוגה מורכבת בזמן אמת עם Remotion.

## הרצה

```bash
cd video-editor
npm install
npm run dev        # http://localhost:3000
```

`npm run dev` מתחבר כברירת מחדל לפרויקט ה-Supabase של העורך (`.env.development`): כניסה במייל, לוח פרויקטים
ושמירה בענן. לעבודה מקומית בלי Supabase: `NEXT_PUBLIC_SUPABASE_URL=` בקובץ `.env.development.local`,
ואז הכול רץ בדפדפן (פרויקט אחד, עיבוד AI מדומה).
- **Supabase** מוסיף התחברות, רשימת פרויקטים, שמירה בענן והעלאת קבצים ל-Storage. ראו "חיבור Supabase".
- **fal.ai** מוסיף וריאציות ותמלול אמיתיים. ראו "מצב ענן".

## מה עובד

| אזור | יכולות |
|------|--------|
| **ספריית מדיה** (ימין) | קליפים לדוגמה, העלאת וידאו ושמע (כפתור או גרירה), לחיצה כפולה מוסיפה לציר הזמן |
| **נגן** (מרכז) | תצוגה חיה של הכול, ניגון, צעד פריים, 9:16 / 16:9 / 1:1, גרירת טקסטים ואימוג'ים על המסך |
| **ציר זמן** (תחתית) | מסלולי וידאו, טקסט, כתוביות וסאונד; גרירה, חיתוך בקצוות, פיצול (`S`), מחיקה, undo/redo, זום. פריטים חופפים מתחלקים לשורות |
| **טקסט ואימוג'י** | 7 תבניות טקסט ו-5 אימוג'ים; אנימציות כניסה (קפיצה, ניתור, החלקה, זום, הקלדה, דהייה), תנועה חוזרת (פעימה, נדנוד, ריחוף, רעידה), יציאה; צבע, רקע, קו מתאר, גודל, סיבוב, מיקום |
| **סאונד** | 10 אפקטים מובנים (נוצרו ב-`scripts/make-sfx.sh`, בלי זכויות יוצרים), העלאת מוזיקה, עוצמה, דהייה פנימה/החוצה, חיתוך; עוצמה/השתקה לסאונד המקורי של כל קליפ |
| **סגנון** | 8 סגנונות צבע לכל קליפ (קולנועי, צבעוני, חם, קר, וינטג', מט, שחור-לבן, נואר) עם עוצמה |
| **כתוביות** | אוטומטיות בחינם: Whisper רץ בתוך הדפדפן (`lib/ai/browser-transcriber.ts`). ידניות: עריכת טקסט, 3 סגנונות, הזזה |
| **ייצוא** | קובץ MP4 (H.264 + AAC) ב-720p או 1080p, נוצר בתוך הדפדפן (`lib/export/render-video.ts`) |
| **שמירה** | אוטומטית: בדפדפן (מקומי) או ב-Supabase (ענן), כולל קבצים שהועלו |
| **חשבון ופרויקטים** | עם Supabase: כניסה בקישור במייל, לוח פרויקטים, יצירה, מחיקה (כולל הקבצים), התנתקות |
| **AI (אופציונלי, בתשלום)** | לשונית "AI" ליצירת וריאציות וידאו מופיעה רק כשמוגדר מודל ב-fal |

**כתוביות אוטומטיות:** בפעם הראשונה הדפדפן מוריד את מודל Whisper מ-Hugging Face (כמה מאות MB, פעם אחת,
ואז הוא נשמר במטמון). ברירת המחדל היא `onnx-community/whisper-small` בעברית. אפשר להחליף ב-`NEXT_PUBLIC_WHISPER_MODEL`
(למשל `onnx-community/whisper-base`, מהיר וקטן יותר אבל פחות מדויק) וב-`NEXT_PUBLIC_WHISPER_LANGUAGE`.

**ייצוא:** עובד ב-Chrome וב-Edge במחשב (WebCodecs). הרינדור משתמש ב-`@remotion/web-renderer`, ששולח ל-Remotion
דיווח שימוש. רישיון Remotion חינמי לאנשים פרטיים ולחברות קטנות; מפתח רישיון (אם יש) נכנס ל-`NEXT_PUBLIC_REMOTION_LICENSE_KEY`.

## חיבור Supabase

1. יוצרים פרויקט ב-[supabase.com](https://supabase.com).
2. ב-SQL Editor מריצים לפי הסדר את שלוש המיגרציות שב-`supabase/migrations/` (0001 עד 0004). הן יוצרות:
   - את טבלת `projects`, עם RLS שמאפשר לכל משתמש לגשת רק לפרויקטים שלו.
   - את ה-bucket הפרטי `media`, שבו כל משתמש כותב וקורא רק בתיקייה שלו.
   - את טבלת `variant_jobs`, שבה נשמרות עבודות ה-AI.
3. (מומלץ) ב-Authentication → URL Configuration מוסיפים ל-Redirect URLs את `http://localhost:3000/auth/callback`
   ואת הכתובת המקבילה של האתר בפריסה. בלי זה הקישור מהמייל מגיע ל-Site URL, וה-middleware מעביר אותו
   ל-callback בעצמו, כך שהכניסה עובדת גם כך כל עוד ה-Site URL הוא כתובת האתר.
4. ממלאים ב-`.env.local` את `NEXT_PUBLIC_SUPABASE_URL` ואת `NEXT_PUBLIC_SUPABASE_ANON_KEY`, ומריצים `npm run dev`.

מה משתנה כש-Supabase מוגדר:
- כל העמודים דורשים התחברות (`middleware.ts`). `/` הופך לרשימת הפרויקטים, וכל פרויקט נפתח ב-`/p/<id>`.
- קבצים עולים ב-tus (resumable) ל-`media/<user>/<project>/`, ומוצגים בכתובות חתומות שמתחדשות בכל פתיחה.
- fal מקבל כתובת חתומה ישירות מ-Storage, בלי העלאה נוספת.
- **וריאציות רצות כעבודות שרת** (`app/api/variants`, `lib/ai/variant-jobs.ts`):
  - השרת שולח את העבודה לתור של fal ושומר שורה ב-`variant_jobs`. הדפדפן רק בודק סטטוס כל 3 שניות.
  - כשהעבודה מסתיימת, השרת מעתיק את הסרטון ל-`media/<user>/<project>/variants/`.
  - סגירת הדף לא עוצרת את העבודה. בפתיחה הבאה העורך ממשיך לעקוב, והשרת אוסף את התוצאה.
  - עבודה שלא הסתיימה תוך שעתיים מסומנת כנכשלה.
- ה-proxy ל-fal פתוח רק למשתמשים מחוברים.

שימו לב:
- הכתובות החתומות תקפות ל-6 שעות. בסשן עבודה ארוך יותר צריך לרענן את הדף.
- במסלול החינמי של Supabase יש מגבלה על גודל קובץ בודד (כרגע 50MB). אפשר להגדיל אותה במסלול בתשלום.

**בדיקות:**
- `supabase/tests/rls.sql` בודק את הבידוד בין משתמשים על Postgres רגיל, בעזרת `supabase/tests/stubs.sql`.
- כל הזרימה נבדקה בדפדפן מול שרת Supabase מדומה שרץ על אותו Postgres עם ה-RLS האמיתי: כניסה,
  יצירת פרויקט, שמירה, העלאה, פתיחה מחדש, בידוד בין משתמשים, מחיקה והתנתקות.
- עבודות השרת נבדקו מול fal מדומה (`FAL_QUEUE_URL`): השלמה, העתקה ל-Storage, יציאה מהדף והמשך בחזרה, וכשל של המודל.
- נבדק מול פרויקט ה-Supabase האמיתי: כניסה בקישור מהמייל, יצירת פרויקט, שמירה, העלאת קובץ ל-Storage ופתיחה מחדש.
- **לא** נבדק מול fal אמיתי (עדיין אין מפתח).

## מצב ענן (fal.ai)

1. מעתיקים `.env.example` ל-`.env.local` וממלאים `FAL_KEY` ו-`FAL_VIDEO_MODEL`.
2. מריצים `npm run dev`. העורך עובר אוטומטית למצב "ענן".

מה קורה מאחורי הקלעים:
- **וריאציות** (`lib/ai/fal-provider.ts`): קובץ המקור עולה פעם אחת ל-fal storage, נשלח לתור של המודל עם
  `video_url`, `prompt` (כולל רמז הסגנון), `strength` ו-`seed`, והסרטון שחוזר נכנס לספרייה ולכרטיס.
  כל מודל מצפה לשדות קצת אחרים: מה שחסר מוסיפים ב-`FAL_VIDEO_EXTRA_INPUT`, ואם שמות השדות שונים,
  משנים את ה-`input` בקובץ הזה.
- **תמלול** (`lib/ai/transcriber.ts`): Whisper על כל קובץ מקור, והמקטעים ממופים לציר הזמן לפי החיתוכים.
- **אבטחה** (`app/api/fal/proxy/route.ts`): המפתח נשאר בשרת. ה-proxy מתיר רק את המודלים שהוגדרו,
  ופתוח רק ב-`npm run dev` עד שיתווסף Auth.

שימו לב:
- המודל מקבל את כל קובץ המקור, לא רק את הקטע שנחתך. לקבצים ארוכים כדאי לחתוך לפני ההעלאה.
- הסכום שמוצג על הכפתור הוא הערכה גסה בלבד. המחיר האמיתי נקבע לפי המודל בעמוד שלו ב-fal.
- מצב הענן נבדק רק עד שלב היציאה ל-fal: ההגבלות של ה-proxy, הפעלת המצב וטיפול בשגיאות.
  קריאה אמיתית למודל עדיין לא נבדקה עם מפתח אמיתי.

## מה מדומה במצב דמו

- **וריאציות:** `lib/ai/provider.ts` (`mockProvider`) מדמה תור ועיבוד, ומחזיר "look" (פילטר צבע / זום / היפוך) על אותו קובץ במקום וידאו חדש.
- **העלאה:** `lib/media/local-upload.ts` שומר את הקובץ בדפדפן (IndexedDB), לא בענן.
- **תמלול:** אין יותר תמלול מדומה בממשק; התמלול האמיתי רץ בדפדפן.

```
stores/editor-store.ts   מצב העורך (Zustand + Immer + zundo ל-undo)
stores/playback-store.ts מצב הניגון (מופרד כדי לא להיכנס להיסטוריה)
lib/ai/                  ממשק ספק, ספק דמו + ספק fal, סגנונות, תמלול (דמו / Whisper)
lib/persistence.ts       שמירה אוטומטית (localStorage + IndexedDB)
app/api/                 config (מה זמין בענן) · fal/proxy (המפתח נשאר בשרת)
app/login, app/auth/     כניסה בקישור במייל, callback, התנתקות
app/p/[id]/              עורך של פרויקט בענן · app/actions.ts: יצירה ומחיקה
lib/backend/             איפה הפרויקט נשמר: local (דפדפן) או cloud (Supabase + tus)
lib/supabase/            לקוחות Supabase לדפדפן ולשרת
lib/editor/              טיפוסים ופונקציות ציר זמן
supabase/migrations/     סכמה לשלב הענן
```

## השלבים הבאים

1. **Proxy לצפייה:** המרה ל-720p ו-thumbnails בענן (Mux או worker עם FFmpeg), כדי שקבצים כבדים ינגנו חלק.
2. **Webhook מ-fal:** כרגע התוצאה נאספת כשהעורך פתוח. Webhook ישלים עבודות גם בלי שאף אחד פותח את הפרויקט.
3. **רינדור:** Remotion Lambda על `TimelineComposition` עם קבצי המקור.
