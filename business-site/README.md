# אתר תדמית לעסק

אתר בעיצוב של PLANIA'S: מסך פתיחה עם הלוגו והמשפט המרכזי, באנר במסך מלא לכל שירות,
עמוד נפרד לכל שירות (למי זה מתאים, מה מקבלים, איך זה עובד, מחיר), כפתור וואטסאפ צף ופוטר.
האתר לא צריך שרת או Base44, ואפשר להעלות אותו לכל אחסון סטטי (Netlify, Vercel, GitHub Pages).

## איך משנים את התוכן

כל התוכן נמצא בקובץ אחד: `src/content.js`.

- **פרטי העסק** (`site`): שם, משפט פתיחה, מספר וואטסאפ, אינסטגרם, מייל וצבע המותג.
- **שירותים** (`services`): כל שירות מקבל באנר בדף הבית ועמוד משלו. אפשר להוסיף או למחוק שירותים.
- **תמונות ולוגו**: מעתיקים את הקבצים לתיקייה `public/images` וכותבים את הנתיב, למשל `'images/living.jpg'`.
  בלי תמונה, האתר מציג רקע בצבע של השירות.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בנייה להעלאה

```bash
npm run build
```

התיקייה `dist` היא האתר המוכן. גוררים אותה ל-Netlify Drop (app.netlify.com/drop) והאתר באוויר.
