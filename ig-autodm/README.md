# תגובה ← הודעה (מחליף למאני צ'ט)

מישהו מגיב מילת מפתח על ריל, ומקבל הודעה פרטית עם כפתור וקישור. אפשר גם להוסיף תגובה פומבית מתחת לתגובה שלו.
המערכת עובדת דרך ה-API הרשמי של אינסטגרם (Private Replies), ורצה על Cloudflare Workers בתוכנית החינמית. אין מנוי חודשי.

## איך זה עובד

1. אינסטגרם שולחת ל-`/webhook` התראה על כל תגובה חדשה. החתימה של מטא נבדקת, ובקשה בלי חתימה נכונה נדחית.
2. אם התגובה נכתבה על ריל שיש לו חוק, ומילת המפתח מופיעה בתוכה (בלי רגישות לאותיות קטנות וגדולות, ובלי ניקוד), היא נכנסת לתור.
3. מהתור יוצאת הודעה פרטית אחת עם כפתור. אם אינסטגרם דוחה את הכפתור, נשלחת הודעת טקסט שהקישור כתוב בסופה.
   אחרי ההודעה נשלחת תגובה פומבית, בנוסח שנבחר באקראי.
4. ניהול הכול נעשה ב-`/admin`, בכניסה עם סיסמה.

## הגנות

- **כל תגובה מקבלת הודעה אחת בלבד.** גם מי שמגיב כמה פעמים על אותו ריל מקבל הודעה אחת.
- **עד 150 הודעות בשעה** (`HOURLY_LIMIT`). השאר מחכות בתור, וכל 5 דקות נשלחת עוד מנה.
- **שגיאה זמנית** (עומס או תקלה אצל מטא) מקבלת עד 5 ניסיונות. אחרי 7 ימים מטא כבר לא מאפשרת לשלוח, והתגובה מסומנת "פג תוקף".
- **לא עונים לחשבון שלך**, כולל התגובות הפומביות שהמערכת עצמה כותבת.
- **מצב בדיקה פעיל כברירת מחדל:** הודעות נשלחות רק לחשבון הבדיקה שמוגדר בדף הניהול.
- **מתג "המערכת פעילה"** עוצר את כל השליחה בלחיצה אחת.
- **שמירת נתונים:** נשמרות רק תגובות שהתאימו לחוק, והן נמחקות אחרי 90 יום.
- **הטוקן של אינסטגרם מתחדש אוטומטית** כל כמה ימים. הוא תקף 60 יום.
- **דף הניהול מוגן:** עוגייה חתומה, חסימה אחרי 8 ניסיונות כניסה שגויים, וחסימת טפסים שנשלחים מאתר אחר.

## התקנה (פעם אחת)

```bash
cd ig-autodm
npm install
npx wrangler login
npx wrangler d1 create ig-autodm      # מעתיקים את ה-database_id לקובץ wrangler.toml
npm run db:init
npx wrangler secret put IG_APP_SECRET
npx wrangler secret put IG_ACCESS_TOKEN
npx wrangler secret put WEBHOOK_VERIFY_TOKEN
npx wrangler secret put ADMIN_PASSWORD
npm run deploy
```

הסודות נכנסים רק דרך הפקודות האלה. הם לא נשמרים בשום קובץ בתיקייה.

**במטא** (Meta for Developers → האפליקציה → Instagram → API setup with Instagram login):
- Webhooks: ב-Callback URL שמים `https://<הכתובת שלך>.workers.dev/webhook`, ב-Verify token את אותה מילה שהכנסת ל-`WEBHOOK_VERIFY_TOKEN`, ונרשמים לשדה `comments`.
- הרשאות: `instagram_business_basic`, `instagram_business_manage_comments`, `instagram_business_manage_messages`.
- בדף הניהול לוחצים "להפעיל עכשיו" אם מופיעה ההודעה שהחשבון עוד לא מקבל התראות על תגובות.

## בדיקות

```bash
npm test          # התאמת מילים ובניית ההודעה
npm run lint      # TypeScript
```

הזרימה המלאה נבדקה עם `wrangler dev` מול שרת אינסטגרם מדומה:
- אימות ה-Webhook וחתימה שגויה
- כניסה לדף הניהול, וחסימת טופס שנשלח מאתר אחר
- בחירת ריל ושמירת חוק
- מצב בדיקה
- כפילויות: אותה תגובה פעמיים, ואותו אדם פעמיים
- התעלמות מתגובות של החשבון עצמו
- גיבוי לטקסט כשהכפתור נדחה
- ניסיון חוזר אחרי שגיאה זמנית
- תגובה פומבית
- חידוש הטוקן

**עדיין לא נבדק מול אינסטגרם אמיתי.**

## חשוב לדעת

- מטא יכולה לשנות את הכללים, לבקש בדיקה של האפליקציה (App Review) או להגביל. תמיד אפשר לכבות את המערכת ולחזור לשליחה ידנית.
- אם מאני צ'ט פעיל על אותה מילת מפתח, צריך לכבות אותו שם. אחרת יישלחו שתי הודעות.
- מי שלא עוקב אחרייך מקבל את ההודעה בתיקיית "בקשות הודעה".
